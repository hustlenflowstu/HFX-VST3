HFX SIMPLE EQ STABILITY BUILD

Purpose: reduce EQ/editor complexity while isolating the Ableton insertion crash.

Changes in this source package:
- Keeps the existing 8-band EQ parameters and 8 filter choices.
- Keeps the frequency, gain, and Q controls for each band.
- Replaces the live FFT/spectrum visual with a simple static response curve.
- Disables graph mouse-drag editing; use the knobs for parameter changes.
- Uses JUCE's standard LookAndFeel for controls instead of the custom HFX LookAndFeel.
- Disables the editor's 20 Hz timer/meter refresh in this diagnostic build.
- Adds guards for empty audio buffers, a null bypass parameter, and invalid sample rate.

IMPORTANT: This source has NOT been compiled or tested in Ableton in this environment.
Do not assume it is crash-free until the GitHub Actions build succeeds and the resulting VST3 is tested in Ableton Live 11.3.43.
