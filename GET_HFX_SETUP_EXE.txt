HFX — GET YOUR WINDOWS INSTALLER (NO MANUAL CODING)

This project is configured to build HFX_Setup_1.0.0_x64.exe on a Windows
GitHub runner. The EXE is not included yet because this environment cannot
run the Windows MSVC compiler or verify the plugin inside Ableton.

ONE-TIME SETUP
1. Sign in or create an account at https://github.com
2. Click + (top right) > New repository. Name it HFX-VST3.
3. Choose Private if you want the source kept private, then create the repository.
4. On the new repository page, choose Add file > Upload files.
5. Upload the CONTENTS of this ZIP's HFX_Windows_VST3 folder. Include the hidden
   .github folder and its workflows/windows-vst3.yml file.
6. Click Commit changes to the main branch.

BUILD THE INSTALLER
1. Open the repository's Actions tab.
2. Select "Build HFX VST3 and Windows Installer".
3. Click Run workflow > Run workflow.
4. Wait for the run to finish with a green check. The first build may take several minutes.
5. Open the completed run and scroll to Artifacts.
6. Download HFX-Setup-Windows-x64. It contains HFX_Setup_1.0.0_x64.exe.
7. Run the EXE on your Windows PC and approve the Windows installer prompt.
8. Restart Ableton Live 11. If needed, open Preferences > Plug-Ins and rescan VST3.

IF THE BUILD FAILS
Open the failed Actions run, expand the red failed step, and send me a screenshot
or copy the error text. Do not edit the C++ files yourself.

IMPORTANT
- This workflow compiles the supplied HFX source; it does not certify the plugin
  as a commercial mastering processor. See README_FIRST.txt for DSP limitations.
- The installer is unsigned. Windows SmartScreen may warn that the publisher is
  unknown. This is normal for an unsigned personal build.
